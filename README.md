# Бизнес Дашборд

React-приложение для просмотра данных из Google Sheets через Apps Script.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173 — перейди в раздел ⚙️ **Настройки** и вставь URL твоего Web App.

## Деплой Apps Script

1. В редакторе Apps Script: **Deploy → New deployment → Web App**
2. Execute as: **Me**
3. Who has access: **Anyone**
4. Скопируй URL и вставь в настройки дашборда

## Сборка для продакшена

```bash
npm run build
```

Папка `dist/` — можно задеплоить на Vercel, Netlify или любой хостинг.

## Что умеет сайт (полный функционал мобильного приложения)

Все данные загружаются **один раз при входе** и живут в памяти: переключение
разделов не делает новых запросов. После любой записи обновляются только
затронутые таблицы (`refresh([...])` в `src/store/DataContext.jsx`), а не
весь набор данных.

| Раздел | Что можно делать |
|---|---|
| Заказы | Создать заказ (рынок, клиент, дата доставки, счётчики по товарам, комментарии, акция «+1 за 10»); открыть заказ — менять состав и количество, добавлять/удалять позиции, менять клиента/рынок/даты, переключать статус, вносить и править оплаты, оформлять возвраты, печатать накладную, удалять заказ |
| Должники | Список долгов, переход в карточку клиента, добавление начального остатка |
| Карточка клиента | Новый заказ для клиента, оплата, взаимозачёт поставщику, начальный остаток; правка и удаление любой записи ленты |
| Поставщики | Справочник: добавление, правка, удаление, начальный долг |
| Карточка поставщика | Поступление товара (с подстановкой цены из справочника сырья), прямая оплата, взаимозачёт с клиентом-должником, начальный остаток; правка и удаление операций |
| Поступления | Общая лента закупок / оплат / зачётов с переходом в карточку поставщика |
| Расходы | Добавление, правка, удаление |
| Возвраты | Список + оформление возврата без привязки к заказу |
| Клиенты | Добавление, правка, удаление |
| Заметки | Создание, правка, отметка «выполнено», удаление |
| Настройки | Переключатель акции, справочник сырья (CRUD), кнопка «Пересчитать всё» (`forceUpdateAll`) |

### Структура новых файлов

```
src/services/api.js          все действия бэкенда (Code.gs) одним модулем
src/store/DataContext.jsx    единое хранилище + точечное обновление таблиц
src/store/UIContext.jsx      тосты и подтверждения вместо alert/confirm
src/components/Form.jsx      модалка, поля, кнопки в тёмной теме
src/components/CreateOrderModal.jsx   оформление нового заказа
src/components/OrderDetailModal.jsx   карточка заказа со всеми операциями
src/components/OpeningBalanceModal.jsx начальные остатки
src/utils/promo.js           акция «+1 за 10» и цена по рынку
src/utils/invoice.js         печать накладной (аналог expo-print)
```

### Про CORS

POST уходит с `Content-Type: text/plain` — иначе браузер шлёт preflight
`OPTIONS`, который Google Apps Script не обрабатывает, и любая запись падает
с CORS-ошибкой. Тело остаётся JSON, на бэкенде читается как
`e.postData.contents`. В деплое скрипта должно стоять
**Execute as: Me**, **Who has access: Anyone**.
